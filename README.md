# LMS Laboratorium Virtual Momentum dan Impuls

Pengembangan dari prototype Virtual Pre-Lab menjadi LMS berbasis web.

Teknologi:
- Next.js
- PostgreSQL Neon Database
- Vercel Deployment
- Babylon.js untuk simulasi 3D

Alur:
Laptop Developer -> GitHub -> Vercel -> Neon Database

Install:
1. npm install
2. npm run dev

Build deployment:
npm run build

Siswa mengakses melalui smartphone.
